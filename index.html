使用說明 How to Use

1. 設定 PAT：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。建立 token 時選擇此 repo 的 Contents 讀寫權限，貼到上方欄位即可。

2. 跨裝置同步：手機瀏覽器開啟此頁，同樣輸入 PAT 一次。之後點「Sync 同步」即可載入最新資料。

3. 年成長率 Annual Growth %（原 App 說明）：僅用於預測模型，假設股價每年以此比率成長。不影響實際損益計算。

4. 更新股價：在每個標的卡片右上角的「現價 Price」欄位直接輸入最新價格，儲存後自動重新計算。
